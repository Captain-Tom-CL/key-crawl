一次安装

连接 Chrome

程序已在 EXE 同目录准备好 extension 文件夹，只需将它加载进浏览器。

更新提示 扩展自动更新后，请在扩展管理页点击“重新加载”，然后刷新已打开的网页。
  1. 1

    打开扩展管理页

    复制下面的地址，在 Chrome 地址栏打开。

    chrome://extensions/
  2. 2

    开启开发者模式

    打开页面右上角的“开发者模式”，点击“加载已解压的扩展程序”。

  3. 3

    选择 extension 文件夹

    选择与 key-crawl.exe 同目录的 extension，完成后将 Key Crawl 固定到工具栏。

Quick Start

四步完成分析

首次使用前，在扩展设置里配置你的模型服务。之后的采集流程只需几次点击。

查看分析结果 ›
  1. ⚙01

    配置模型

    填写 API 地址、模型、API Key 和分析提示词并保存。

  2. ＋02

    批量打开

    在列表页填写链接 CSS 选择器，点击“批量打开”。

  3. ▶03

    发送并分析

    页面加载后批量发送内容，随后点击“开始分析”。

  4. ✓04

    查看与导出

    检查结构化结果，并根据需要导出 CSV 文件。

⌂

数据只留在本机

配置、采集页面和分析结果都位于 EXE 同目录的 data 文件夹。请妥善保管 API Key。

◉

保持服务运行

使用扩展期间请不要关闭 Key Crawl。默认服务地址为 http://127.0.0.1:1323。
